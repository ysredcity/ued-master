# UEDMaster 设计记录（2026-10-15）

## 背景

用 `redesign-existing-projects` 优化一份 AI 生成的 CRM 原型，效果被用户认可。新产品早期没有设计系统，需要一个 skill 同时覆盖「从需求生成 demo」和「优化已生成 demo」。

## 决策

| 问题 | 决定 | 理由 |
|---|---|---|
| 规则多少 | 少规则，只写底线 | 无设计系统时，规则会限制模型判断（用户） |
| 上游内容 | 完全复用，正文逐字放标记区 | 保留已验证的效果；便于对比和同步上游 |
| 增补位置 | 标记区之前 | 不改上游字句，覆盖关系在增补里说明 |
| 品牌色 | 只定义 teal-600 `#009689` / teal-700 `#00786F` | `#00AAA6` 对比度不足；只给色值，不引入完整色板（用户） |
| 色值引入方式 | 只用色值，不引入 Tailwind 框架 | demo 保持单文件零依赖（用户） |
| 结构 | 参照 UEDJudge：治理文件 + releases + tests（cases/outputs 不入库）+ docs/plans + steering | 与用户其他 skill 仓库一致 |
